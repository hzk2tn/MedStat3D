Our package, MedStat3D, is a R package for visualizing statistical results on segmented medical imaging data. It takes segmented data for organs such as the heart, brain, and liver and enables interactive, 3D visualizations and statistical analysis for each organ, using MedStat3D's organ atlas. Because each organ has its own irregular shape, this kind of interactive, 3D plotting currently requires researchers to work with 3D meshes and create a lot of custom code. Our goal is to reduce that workload, enabling users to focus on analyzing and drawing conclusions from their data visually with only a few function calls.
The package is intended for anyone who works with segmented, multidimensional data on organs, such as medical imaging researchers, biostatisticians, and clinicians. Instead of writing new plotting code for each organ, users will be able to apply consistent visualizations across different parts of the body.
We expect two major challenges. The first is technical: building visualizations that work across organs with different shapes, dimensions, and data structures. The second is organizational: coordinating work across a large group and keeping the package's scope focused and achievable.
To divide the work, we will assign team members to organ-specific branches, with each subgroup responsible for one organ. For code review, each person will push their work to an individual branch, and a teammate will review it before it is merged into that organ's branch. This process will help us maintain code quality and avoid merge conflicts.
